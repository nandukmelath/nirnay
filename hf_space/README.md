# Nirnay demo

Ask **choice**, **yes / no** or **rating** questions about any text or JSON and get calibrated probabilities in one
pass, on CPU. Same question format as Laya / Jev (`/v1/systemone`).

Model card, benchmarks against Laya and Jev, and install instructions: [nandukmelath/nirnay](https://huggingface.co/nandukmelath/nirnay).
Code: [github.com/nandukmelath/nirnay](https://github.com/nandukmelath/nirnay).
